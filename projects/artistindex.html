About This Project

The Artist Index is a web application for hosting a database of artists that I follow on a variety of social media platforms. Think Twitter, Bluesky, and Pixiv just to name a few. It uses Flask and SQLite for the backend and HTML, CSS, and JavaScript for the frontend.

I'll keep this brief since I currently host an instance of the Artist Index, which has its own 'About' page. You can visit the Artist Index here. You can also find a link to the GitHub repository in the 'About' page, if you are interested in viewing the source code.
