About This Project

This is a Python port of my Perona-Malik edge enhancement script. My original script was written in MATLAB and was used for an academic project in MACM 416. The project was mainly about analyzing the properties of the time-stepping and spatial derivative schemes used by the Perona-Malik edge enhancement algorithm.

I made this Python port because I thought the algorithm was very interesting in how it visually affected images, but also because I really enjoyed analyzing the mathematic equations behind the Perona-Malik edge enhancement algorithm. I wanted my code to be easily shared, but since MATLAB requires an annual subscription to use, I decided to rewrite my code in Python.

This project was a valuable learning experience in Python, as I implemented several optimizations in the Python scripts that weren't present my original MATLAB scripts.

One major time save was utilizing parallel processes to speed up each iteration of the algorithm. The algorithm needs to be run on each colour channel of the image, but the colour channels do not interact with each other within each iteration. Therefore, I can process each colour channel in parallel, rather than in sequence. This reduced the algorithm runtime down to 33% of the sequential runtime.

Another big time save was making use of convolutions to process colour channels, rather than nested for loops. When processing a colour channel, the algorithm needs to view each pixel intensity and perform calculations based on its neighboring pixel intensities. The original MATLAB code just used for loops since the project wasn't being graded on efficiency, rather it was more focused on the analysis of the algorithm. However, nested for loops aren't very efficient and convolutions are a great way to run calculations with neighboring values. This was a smaller optimization, though it still made a significant difference in runtime.
